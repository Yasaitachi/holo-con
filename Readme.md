# ホロコン！
スマートフォンやタブレットをコントローラーとして使い、PC版ゲームを操作するアプリケーションです。

## 動作環境

### Androidアプリ
- Android 7.0（API 24）以上

### PCサーバー
- Windows 11以上
- Python 3.11（64-bit）推奨
- HTML画面表示用のMicrosoft Edge WebView2 Runtime

## 導入方法

### Android端末へのインストール

1. `Release`から最新のAPKファイルをダウンロードします。
2. PCでダウンロードした場合は、USBケーブルなどでAPKファイルをAndroid端末へ転送します。
3. Android端末でAPKファイルをタップし、表示されるアプリ名が「ホロコン！」であることを確認してインストールします。
   - Androidから「不明なアプリのインストール」を求められた場合は、APKを開いたアプリに限って許可してください。
   - 配布元が信頼できない場合はインストールしないでください。

### Windows PCサーバーのインストール

1. サーバーとして使うWindows PCで、`Release`から`server.zip`をダウンロードします。
2. `server.zip`を右クリックして`すべて展開`を選びます。
3. 展開したサーバーフォルダーに、少なくとも次のファイルがあることを確認します。
   - `server.py`
   - `server_ui.html`
   - `requirements-server.txt`
   - `requirements-bluetooth.txt`（Bluetooth接続を使う場合）
4. Python 3.11（64-bit）をインストールします。インストーラーでは`Add python.exe to PATH`を有効にしてください。
5. Microsoft Edge WebView2 Runtimeがインストールされていることを確認します。サーバー起動時にWebView2関連のエラーが表示された場合は、WebView2 Runtimeをインストールしてください。
6. `server.py`があるフォルダー内で右クリックし、`ターミナルで開く`を選びます。
7. サーバーに必要なライブラリをインストールします。

   ```powershell
   py -m pip install -r requirements-server.txt
   ```

8. Bluetooth接続を使う場合は、Bluetooth用ライブラリもインストールします。Wi-Fi接続のみの場合は不要です。

   ```powershell
   py -m pip install -r requirements-bluetooth.txt
   ```

9. 同じターミナルからサーバーを起動します。

   ```powershell
   py server.py
   ```

### 接続設定

- **Wi-Fi接続**：PCとAndroid端末を同じWi-Fiネットワークに接続します。サーバー画面で`Wi-Fi`を選び、必要に応じてポート番号を設定します（初期値：8080）。Windowsファイアウォールが通信の許可を求めた場合は、プライベートネットワークで許可してください。
- **Bluetooth接続**：事前にWindowsとAndroid端末をペアリングし、Windows側でBluetoothの着信COMポートを設定します。サーバー画面で`Bluetooth`を選択し、その着信COMポートを指定してください。
- 入力先をゲームウィンドウに限定する場合は、サーバー画面の`対象ゲームウィンドウ`からゲームを選びます。ウィンドウが表示されていない場合は`再検出`を押してください。`すべてのウィンドウ（限定しない）`を選ぶと従来どおり限定しません。
- 接続方式などを設定したら、サーバー画面の`サーバーを起動`を押し、Androidアプリでも同じ接続方式を選択して接続してください。

## アプリケーションの利用方法

### はじめに

1. Windows PCでサーバーを起動し、サーバー画面でWi-FiまたはBluetoothを選びます。
2. PCサーバーの`サーバーを起動`を押します。
3. Androidアプリを起動し、左上の`設定`を開いて`接続`タブを選びます。
4. サーバーと同じ接続方式を選び、接続先PCを指定します。
   - **Wi-Fi**：`Wi-Fi自動探索`でPCを探し、一覧のPCの`接続`を押します。見つからない場合は`手動でIP追加`にPCのIPアドレスを入力します。
   - **Bluetooth**：一覧からペアリング済みPCを選び、`接続`を押します。表示されない場合はAndroidとWindowsのBluetoothペアリングを確認してください。
5. `接続テスト`を押し、接続成功を確認します。画面上部が`通信中`になれば接続されています。
6. ゲームを起動してゲーム画面を前面にし、Android画面のレーンをタップして操作します。ゲーム中はサーバーを起動したままにしてください。

### ゲーム内キーバインドを合わせる

**アプリのレーンに割り当てたキーと、ゲーム内の各レーンのキー設定を必ず同じにしてください。** キーが一致しないと、タップしても意図したレーンを操作できません。

初期設定のレーンキーは次のとおりです。

| アプリのレーン | 初期キー |
|---|---|
| L3 | S |
| L2 | D |
| L1 | F |
| R1 | J |
| R2 | K |
| R3 | L |

ゲーム側で別のキーを使う場合は、アプリの`設定`→`操作キー`タブで各レーンの割り当てを変更し、ゲーム内のキーバインドも同じキーに設定してください。キーを変更した後は、画面下部に表示されるレーン名とキーを確認してください。

### 画面上の操作

- **レーン**：画面内のレーンをタップして押下します。複数のレーンを同時にタップできます。指を離すとキーも離れます。
- **PAUSE**：画面右上のボタンでポーズキーを送信します。初期キーは`Q`です。`設定`→`操作キー`タブで変更できます。
- **PING**：画面上部にPCとの通信遅延をミリ秒で表示します。`設定`→`画面`タブの`上部バーにPING表示`で表示を切り替えられます。

### アプリの設定

左上の`設定`から、次のタブを使用できます。設定は自動で保存されます。

- **接続**：Wi-Fi／Bluetoothの選択、接続先PCの探索・選択、Wi-Fi接続先IPの手動追加、接続テストを行います。Bluetoothを選ぶ場合は必要な権限を許可してください。
- **画面**：端末の画像を背景に設定できます。`平面モード`ではレーンが長方形になります。`レーン全体の幅`でレーン幅を調整でき、範囲外をタップしても入力されません。PING表示もここで切り替えます。
- **操作キー**：PAUSEキー、タイミング調整用キー、6レーンそれぞれのキーを設定します。`送信テスト`はタイミング調整用キーをPCへ1回送信します。

### PCサーバー画面

- **アプリ画面プレビュー**：アプリが接続すると、レーン配置、キー割り当て、表示モード、設定済みの背景画像がPCプレビューへ同期されます。Bluetooth接続では背景画像を小分けに転送し、その間もゲーム入力を優先します。背景画像を変更・解除した場合もプレビューへ反映されます。
- **サーバー設定**：接続方式、Wi-FiポートまたはBluetooth着信COMポート、入力先の対象ゲームウィンドウを設定してサーバーを起動・停止します。ウィンドウを選ぶと、そのウィンドウが前面にある間だけキーを送信します。サーバー稼働中は接続設定を変更できません。
- **サーバーログ**：サーバーの起動状態、接続状況、エラーを確認できます。

ゲームへ入力できない場合は、PCサーバーが起動中か、Androidアプリが`通信中`か、ゲームが前面にあるか、アプリとゲームのキーバインドが一致しているかを確認してください。

## フォルダー構成

開発用フォルダーは用途ごとに次のように分けています。

| フォルダー | 内容 |
|---|---|
| `android/` | Androidアプリの作業用Kotlinソース |
| `assets/` | アイコンなどの画像素材 |
| `docs/` | このREADMEなどの説明資料 |
| `releases/current/` | 現在配布する署名済みAPK |
| `releases/archive/` | 以前に出力したAPK |
| `server/` | PCサーバー本体、HTML画面、Python依存関係ファイル |
| `signing/` | 署名鍵の保管場所などのローカル管理情報 |

`signing/`フォルダーは公開用の配布物に含めないでください。秘密鍵本体はこのフォルダーではなく、Windowsユーザー領域に保管しています。
